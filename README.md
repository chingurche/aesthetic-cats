# aesthetic-cats

Игровой процесс
Игрок исследует подводный мир и занимается собирательством. На дне лежат
различные артефакты и предметы — чем больше глубина, тем они ценнее. При
возвращении на поверхность все подобранные предметы конвертируются во
внутриигровую валюту. В главном меню за нее можно приобрести улучшения для
скафандра и кислородного баллона, что позволяет игроку исследовать океан еще дольше и
еще глубже.
Архитектурные паттерны и системы управления

В проекте реализован ряд архитектурных решений, обеспечивающих
сопровождаемость и тестируемость кода:
1. Single Entry Point – единая точка входа приложения, управляющая порядком
инициализации всех подсистем, что позволяет исключить недетерминированное
поведение при запуске.
2. Dependency Injection (DI) на базе контейнера VContainer – обеспечивает
инверсию управления и слабую связанность компонентов. Сервисы регистрируются с
указанием времени жизни (Singleton, Scoped, Transient), что упрощает тестирование и
замену реализаций.
3. Addressables – система управления ассетами, реализующая асинхронную загрузку
контента по строковому ключу. Применение Addressables позволяет снизить потребление
оперативной памяти и реализовать механизм обновления контента без пересборки
исполняемого файла.
4. MVC (Model-View-Controller) – паттерн, разделяющий данные, логику и
представление. Модель (Model) хранит состояние, представление (View) отвечает за
отображение, контроллер (Controller) обрабатывает логику и связывает компоненты.
Данный подход обеспечивает однозначное разделение ответственности между
компонентами системы.
